JCI NEXO — Setup

Get running in ~5 minutes

Prerequisites

ToolVersionCheck
Python3.11+python3 --version
Node.js18+node --version
npm(bundled with Node)npm --version
Gemini API key is optional. Without it, the AI features (Ask Wellington, retention advice, outreach emails) automatically use a built-in deterministic fallback, so everything still works. Get a free key at aistudio.google.com/app/apikey.

Steps

1

Clone the repository

git clone https://github.com/amithkaitheri/JCInexo.git
cd JCInexo
2

Configure environment files

# Backend
cp backend/.env.example backend/.env
# (optional) open backend/.env and set:  GEMINI_API_KEY=your-key

# Frontend
cp frontend/.env.example frontend/.env
3

Install dependencies

# Backend (Python)
cd backend
pip install -r requirements.txt
cd ..

# Frontend (Node)
cd frontend
npm install
cd ..

Tip: use a Python virtual environment — python3 -m venv .venv && source .venv/bin/activate — before pip install.

4

Seed demo data (recommended)

./seed.sh

Seeds ~30 members, engagement activities, renewals, computed health scores, and 4 pending membership applications for the demo. (Same as cd backend && MEMBER_TRACKER_DB_PATH=member_tracker.db python3 seed_demo.py.)

5

Run the app

./start.sh          # starts backend (:8000) + dashboard (:5176)

Then open http://localhost:5176. To stop everything:

./stop.sh
Manual alternative (two terminals): 
# Terminal 1 — backend
cd backend
python3 -m uvicorn member_tracker.api.app:app --host 0.0.0.0 --port 8000

# Terminal 2 — frontend
cd frontend
npm run dev
6

Sign in

Username: president  ·  Password: jciottawa2026

Verify it's working

curl http://localhost:8000/api/health
# → {"status":"ok","service":"member-tracker","version":"1.0.0"}

Interactive API docs: http://localhost:8000/docs

Environment variables

FileVariablePurpose
backend/.envGEMINI_API_KEYEnables Gemini AI (optional; falls back if absent)
backend/.envGEMINI_MODELModel name (default gemini-1.5-flash)
backend/.envMEMBER_TRACKER_API_KEYAdmin key (default member-tracker-dev-key)
backend/.envMEMBER_TRACKER_DB_PATHSQLite path (default member_tracker.db)
frontend/.envVITE_API_BASE_URLBackend URL (default http://localhost:8000)
frontend/.envVITE_API_KEYMust match the backend admin key

Troubleshooting

Port already in use — run ./stop.sh, or override ports: MGT_BACKEND_PORT=8001 MGT_FRONTEND_PORT=5177 ./start.sh.
AI answers look generic / say "template" — that's the deterministic fallback. Set GEMINI_API_KEY in backend/.env and restart the backend.
Empty dashboard — re-run the seed step (step 4).
Logs — check .run/backend.log and .run/frontend.log.
